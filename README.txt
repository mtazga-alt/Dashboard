قضايتي — نسخة PWA تعمل بدون اتصال (GitHub Pages)

الرفع:
1) على GitHub أنشئ مستودعاً جديداً (مثلاً qadayti).
2) Add file > Upload files: اسحب كل محتويات هذا المجلد (ومعها مجلدا assets و fonts) إلى جذر المستودع، ثم Commit.
3) Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4) بعد دقيقة افتح: https://اسم-حسابك.github.io/qadayti/

التثبيت على الموبايل:
- افتح الرابط مرة واحدة وانت متصل بالإنترنت.
- Chrome: القائمة ⋮ > تثبيت التطبيق.  آيفون (Safari): مشاركة > إضافة إلى الشاشة الرئيسية.
- بعدها يعمل التطبيق بالكامل بدون إنترنت.

نقل بياناتك من النسخة القديمة:
- في التطبيق القديم: الإعدادات > نسخة احتياطية > تنزيل ملف النسخة.
- في النسخة الجديدة: الإعدادات > استرجاع من ملف.

التحديث لاحقاً:
- ارفع الملفات الجديدة، وغيّر في sw.js السطر  const CACHE = 'qadayti-v1'  إلى v2 ثم v3 ... وهكذا.

ملاحظة: «التطبيقات المخصصة» وصفحة «تحويل من PDF» والشعار تُحفظ الآن داخل الجهاز بدل سيرفر المنصة.
